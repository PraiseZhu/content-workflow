# X trending style weekly pick

1. Read the library `index.md` and every `style.md` for this ISO week's day folders.
2. Rank sets by: personal-brand fit (标签强度), distinctiveness vs. the user's house style (borrowable without copying), then engagement. Keep genre variety: at most 2 from one genre.
3. Pick the top 5. For each: one line on why, the title, the post link, and attach cover + inline images (file:// paths) so the user can see them.
4. Add a short line with the week's count vs. target (e.g. 50 sets).
5. Write in the user's language, plain and short. End by asking which ones they want to adopt. Do not change the user's own style files; wait for their pick.
6. Save the pick list as `<root>/weekly/<YYYY-Www>.md`.
