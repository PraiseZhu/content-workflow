# 02 · 选题 Topic selection

**节奏**：每周五 08:04（Asia/Shanghai）定时任务自动出 10 个选题（prompt 见 [routines/weekly-topics.md](../routines/weekly-topics.md)）。

## 来源
- X 上 AI 相关的热门内容（近 7 天，按互动排序），只看与作者 IP 标签相关的。
- IP 标签（可配置，例）：AI 协作 / 多 Agent 组织 / 自动化 QA / 设计与 AI / 个人工作流。
- 作者自己的一手经历（作者口述，不能编）。

## 每张选题卡必须包含
1. 中文标题 + 英文标题
2. 为什么值得写（反常识点 / 热度证据链接）
3. 对应哪个 IP 标签
4. **开头冲突或场景**：可直接用作开头三行
5. **作者必须口述补充的清单**：哪些一手材料、数字、经历只有作者有（缺了就标 `[待作者补]`）
6. 门槛自评 / 总分

## 附：一周数据复盘
发布满一周的文章，附阅读、点赞、转发、收藏、X 曝光等，和上一篇对比，给一句结论（见 [09](09-history-and-review.md)）。

## 规则
- 作者挑选之前不写提纲。
- 选题只做一次，中英共用。
- 本地受众规则（可配置）：例如「不引用某地区的推文或人物作为论据」。写在 `config/voice.md`。

详细交互流程：[skill/wewrite/references/weekly-topics.md](../skill/wewrite/references/weekly-topics.md)、[skill/wewrite/references/topic-selection.md](../skill/wewrite/references/topic-selection.md)。
