# 03 · 提纲与作者口述 Outline & briefing

1. 读选中的选题卡 + 作者口述的观点（**作者观点做主导**，覆盖卡上的默认观点）。
2. 提纲结构（X 热门长文结构）：
   - **拔高的论点**（thesis）放在开头，一句话能复述；
   - 从**组织 / 机制**角度切入，而不是工具清单；
   - 2–4 个咬合的论点，每节挂证据；必有一节反面/边界；
   - 一句判断收口，收在行动（谁适合 + 下一步）。
3. 每节标出所需材料；缺一手证据标 `⚠️ 补或删` / `[待作者补]`，禁止空心节。
4. 作者的标题和结论句写进 `article.yaml` 的 `locked:`，此后逐字保留。
5. 闸门：`deai_lint.py gate --stage outline`。✋ 确认①：作者确认提纲。

中英共用同一提纲，只确认一次。
