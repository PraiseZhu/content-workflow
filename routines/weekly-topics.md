# Routine · 每周 10 个选题（Weekly topics）

- **时间**：每周五 08:04（Asia/Shanghai），cron `4 8 * * 5`
- **输出**：一份选题报告（同时存到 `${CONTENT_ROOT}/selections/YYYY-Www-选题.md` 或 wewrite `outlines/YYYY-Www.md`）

## Prompt

```
你是作者的写作搭档。今天是周五，请出本周选题。

1. 用公开的 X 读取工具，搜过去 7 天 AI 相关的热门内容（按收藏/曝光/互动排序），只保留和作者 IP 标签相关的：
   <IP_TAGS，例：设计师、摄影师、AI 时代组织运转、研发机制、自动化工作流>。
   遵守 config/voice.md 的本地受众规则（例：不引用某地区的推文或人物作为论据，热度只作为"大家在聊什么"的信号）。
2. 给出 10 个选题，中英各一个标题。每个选题包含：
   - 中文标题 / English title
   - 为什么值得写（一句反常识判断 + 热度证据链接）
   - 对应 IP 标签
   - 开头三行可直接用的冲突或场景
   - 作者必须口述补充的清单（只有作者有的一手经历、数字、截图；缺了就写 [待作者补]）
   - 总分（热度 / 与 IP 契合 / 作者一手材料可得性 / 可写深度）
   不编造任何经历、数字、故事。不点公司、产品、项目名。
3. 一周数据复盘：读 history.yaml，凡发布满 7 天的文章，拉数据（微信：阅读/点赞/在看/转发/收藏；X：曝光/点赞/转发/书签），
   与上一篇对比，各给一句结论（什么起作用了、下次改什么）。没有满一周的文章就写"本周无复盘"。
4. 报告顶部 3 行摘要：推荐优先写哪 2 个、为什么、需要作者本周补什么。
5. 不要写提纲，等作者挑选。
```

## 完成标准
- 定时任务状态 succeeded；10 张卡齐全；复盘段存在（或明确写"本周无复盘"）。
