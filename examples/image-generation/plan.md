# Example Studio 文章配图方案 v2（正文不改动）

## 视觉系统
- 颜色：黑 #000 / 白 #FFF；极光绿 #7CD844、蓝 #00BDFF、柠檬 #B6F37C（胶囊标签/强调）；studio 蓝 #00BDFF；search 橙 #FF8A00（待 Figma 变量确认）。
- 字体：Helvetica Neue / PingFang SC（本机渲染用 Inter + Noto Sans CJK SC 替代，正式出图建议在装有 Helvetica Neue/苹方的环境重渲）。
- 背景：黑底 + 绿蓝模糊光斑 + 竖条纹（呼应竖切片球体 logo）；信息图背景压暗至 40%。
- 组件：白色圆角卡片 r28、柠檬胶囊、编号大数字（蓝）、细分割线、竖切片 logo 图标。
- 图内文字全部取自原文逐字摘录；分类标签（如「已可体验」「免费」）为短标签。

## 现有配图问题
仅有封面横幅、两条扁平 logo 条（studio 蓝 / search 橙）和公众号二维码，没有一张信息图；"走到了哪一步"等长列表全靠文字，手机端难扫读。建议保留封面与二维码，logo 条可由 06 组件图替代。
